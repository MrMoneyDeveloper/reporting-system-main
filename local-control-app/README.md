# CX Experts Reporting Dashboard

This folder is the Cloudflare Pages frontend for the reporting system.

Apps Script remains the backend that reads Google Sheets, stores credentials in Script Properties, runs source syncs, generates reports, and calls the AI provider. Cloudflare Pages serves the React dashboard and uses the project-coded server-side Pages Function under `/api` as the same-origin bridge to Apps Script.

## Cloudflare Pages Settings

Use these settings when creating the Pages project:

| Setting | Value |
| --- | --- |
| Framework preset | None is OK, or React / Vite |
| Root directory | `local-control-app` |
| Build command | `npm run build` |
| Build output directory | `dist` |
| Production branch | `main` |

Cloudflare sometimes resets the framework preset to `None`. That is fine as long as root directory, build command, and output directory are correct.

## API Connection

The Pages Function includes the current Apps Script web app URL in code so users do not need to paste a URL into the dashboard. Cloudflare environment variables are optional overrides:

```text
APPS_SCRIPT_WEB_APP_URL=https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec   optional override
INTERNAL_API_SECRET=the same value as Apps Script Script Property INTERNAL_API_SECRET  optional protected POST mode
```

Without `INTERNAL_API_SECRET`, the bridge calls the Apps Script JSON dashboard endpoints through `doGet`. With `INTERNAL_API_SECRET`, it uses the protected `doPost` path. The browser never receives secrets. It calls same-origin endpoints such as `/api/bootstrap`, `/api/metrics`, `/api/insight`, `/api/hard-refresh`, `/api/sync-status`, and `/api/export.csv`.

## Local Test

```bash
npm install
npm run build
npm run preview
```

For full local API testing, use a Cloudflare Pages Functions local runner with the same environment variables. A normal Vite preview only serves the static React app.

## Notes

- Do not put Groq, Zendesk, Google, or internal API secrets in frontend code.
- Secrets stay in Apps Script Script Properties and optional Cloudflare Pages environment variables.
- The CSV export is generated by the Cloudflare API proxy from Apps Script dashboard metrics.
